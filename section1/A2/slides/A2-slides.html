BLOQUE 1

Conceptos que debes dominar primero.

Índice

Este apartado ayuda a reconocer y relacionar Índice dentro del tema.

Qué es un proceso

Un proceso es una instancia de un programa en ejecución. Cuando se inicia una aplicación, el sistema operativo crea un proceso para poder ejecutarla.

Estados de un proceso

Durante su vida, un proceso puede pasar por varios estados: Nuevo (New): el proceso se está creando. Listo (Ready): preparado para ejecutarse, esperando CPU.

BLOQUE 2

Funcionamiento y relaciones importantes.

Multitarea y planificación

La multitarea permite que varios procesos avancen de forma concurrente. El planificador (scheduler) del sistema operativo decide: Mononúcleo: la CPU alterna rápidamente entre procesos.

Qué es un hilo (thread)

Un hilo (thread) es la unidad mínima de ejecución que el sistema operativo puede planificar. Pueden realizar tareas diferentes al mismo tiempo.

Diferencias entre procesos e hilos

👉 Un proceso contiene uno o varios hilos.

BLOQUE 3

Criterios para decidir y comprobar.

Concurrencia y paralelismo

Este apartado ayuda a reconocer y relacionar Concurrencia y paralelismo dentro del tema.

Concurrencia

La concurrencia ocurre cuando varias tareas progresan en el tiempo, aunque no se ejecuten exactamente al mismo instante. Un solo núcleo alternando entre varios hilos.

Paralelismo

El paralelismo ocurre cuando varias tareas se ejecutan simultáneamente, gracias a: Dos hilos ejecutándose a la vez en dos núcleos distintos.

Pregunta guía. ¿Qué dato necesito mirar para saber si esto es compatible, correcto o seguro?
