# Anexo 7 - Intel vs AMD

## Resumen del anexo

Este anexo compara las plataformas de **Intel** y **AMD** desde la perspectiva de un taller: arquitecturas recientes, compatibilidad, consumo, rendimiento y criterios de eleccion segun el uso real.

## Que aprenderas

- Identificar las familias y microarquitecturas actuales de Intel y AMD.
- Explicar diferencias practicas entre plataformas y sockets.
- Valorar rendimiento, consumo y compatibilidad segun el caso de uso.
- Recomendar un procesador en escenarios reales de cliente.
