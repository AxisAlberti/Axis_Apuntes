BLOQUE 1

Conceptos que debes dominar primero.

Arquitectura SISC (Single Instruction Set Computer)

Este apartado ayuda a reconocer y relacionar Arquitectura SISC (Single Instruction Set Computer) dentro del tema.

¿Qué es SISC?

La arquitectura SISC se basa en una idea muy simple: 👉 el procesador dispone de una única instrucción o de un conjunto extremadamente reducido de instrucciones. Toda operación, por compleja que sea, se realiza repitiendo esa instrucción básica con distintos datos.

Características principales

Conjunto de instrucciones mínimo o único. Funcionamiento muy simple a nivel conceptual.

Bloque conceptual 1
Desarrolla estos conceptos con calma. Conviene acompañarlos con ejemplos cotidianos antes de pasar a la parte más técnica.

BLOQUE 2

Funcionamiento y relaciones importantes.

Ventajas

Fácil de implementar a nivel teórico. Útil para comprender conceptos básicos de arquitectura de computadores.

Desventajas

Muy poco eficiente para tareas reales. Gran número de ciclos para realizar operaciones complejas.

Uso real

La arquitectura SISC no se utiliza en procesadores comerciales modernos. Su importancia es principalmente educativa, para explicar: Cómo se construyen operaciones complejas a partir de operaciones simples.

Bloque conceptual 2
Aquí interesa que el alumnado no memorice piezas aisladas. Refuerza causas, consecuencias y dependencias entre componentes o conceptos.

BLOQUE 3

Criterios para decidir y comprobar.

Arquitectura CISC (Complex Instruction Set Computer)

Este apartado ayuda a reconocer y relacionar Arquitectura CISC (Complex Instruction Set Computer) dentro del tema.

¿Qué es CISC?

La arquitectura CISC se basa en la idea de que el procesador debe disponer de un conjunto amplio y complejo de instrucciones, capaces de realizar operaciones avanzadas en una sola instrucción. Reducir el número de instrucciones por programa.

Características principales

Conjunto de instrucciones muy amplio. Instrucciones que pueden realizar varias operaciones a la vez.

Pregunta guía. ¿Qué dato necesito mirar para saber si esto es compatible, correcto o seguro?
Bloque conceptual 3
Haz explícito el criterio técnico. Es mejor que el alumnado aprenda a justificar decisiones que a repetir una lista de características.
