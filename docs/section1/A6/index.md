# Anexo 6 - BIOS, UEFI y proceso de encendido del PC

## Resumen del anexo

Este anexo explica el proceso de encendido del PC, el POST, los pitidos de error y la busqueda del dispositivo de arranque. Se relaciona con el BIOS/UEFI y con las tareas basicas de diagnostico.

## Que aprenderas

- Describir las fases del arranque desde el encendido.
- Explicar que es el POST y que comprueba.
- Interpretar errores tipicos de arranque y pitidos.
- Entender como se busca el sistema operativo.
