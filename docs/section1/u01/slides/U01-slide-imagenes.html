Introducción a los sistemas informáticos

Resumen visual de los bloques clave

Un sistema informático es un conjunto coordinado de componentes físicos y lógicos que transforman datos en información útil.

  • El hardware ejecuta operaciones: CPU, memoria, almacenamiento y periféricos.
  • El software organiza el trabajo: sistema operativo, aplicaciones y utilidades.
  • El firmware inicia y configura el equipo: BIOS/UEFI y controladores básicos.

Vista general del sistema

Este esquema resume el “camino” de la información: entrada de datos, procesamiento y salida.

  • Los dispositivos de entrada capturan datos del usuario o del entorno.
  • La CPU y la RAM procesan y mantienen los datos activos.
  • La salida presenta resultados y el almacenamiento conserva la información.

Diagrama básico de CPU

La CPU coordina instrucciones, mueve datos entre registros y ejecuta operaciones en la ALU.

  • Unidad de control: interpreta instrucciones y dirige el trabajo.
  • ALU: realiza operaciones lógicas y aritméticas.
  • Registros: almacenan datos inmediatos para acelerar el procesamiento.

Hardware, software y firmware

El hardware ejecuta, el software ordena y el firmware coordina el arranque.

Si falla uno de estos niveles, el sistema no puede iniciar o funcionar con normalidad.

El objetivo de la unidad es reconocerlos y entender su relación.
