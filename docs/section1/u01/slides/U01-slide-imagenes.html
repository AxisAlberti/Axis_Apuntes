Idea clave

Un sistema informático no es solo una torre.

Hardware

Componentes físicos: placa base, CPU, RAM, almacenamiento, fuente, tarjetas y periféricos.

Software

Programas que indican al hardware qué debe hacer: sistema operativo, aplicaciones y utilidades.

Datos

Información que entra, se procesa, se almacena y se muestra como resultado útil.

Usuarios

Personas que usan el sistema y dan sentido al proceso: estudiar, crear, comunicar o resolver problemas.

Componentes de un sistema
Explica que un fallo puede estar en cualquiera de estas capas. Si una app no imprime, no siempre es culpa de la impresora: puede ser driver, permisos, cola o configuración.

Ciclo básico de funcionamiento

Todo sistema informático sigue un recorrido de información.

01

Entrada

El usuario o un dispositivo introduce datos: teclado, ratón, sensor, escáner o red.

02

Procesamiento

La CPU interpreta instrucciones y transforma datos con ayuda de la RAM.

03

Almacenamiento

Los resultados pueden guardarse de forma temporal o permanente.

04

Salida

La información vuelve al usuario como imagen, sonido, impresión, archivo o respuesta.

Entrada · Proceso · Almacenamiento · Salida
Usa un ejemplo simple: escribir una frase en un procesador de texto. El teclado introduce datos, el sistema los procesa, la RAM mantiene el documento activo, el SSD lo guarda y la pantalla muestra el resultado.

Arquitectura base

Von Neumann: datos e instrucciones comparten memoria.

La idea potente

El ordenador no se recablea para cada tarea. Carga instrucciones en memoria y la CPU las ejecuta una tras otra.

CPU ejecuta instrucciones.

Memoria guarda datos y programas activos.

Entrada/Salida conecta el sistema con el exterior.

Modelo de Von Neumann
Aclara que este modelo es una simplificación, pero muy útil para entender los PCs actuales. Menciona que tanto instrucciones como datos viven en memoria, y que la CPU los va buscando, decodificando y ejecutando.

Dentro de la CPU

La CPU coordina, calcula y guarda resultados inmediatos.

Unidad de control

Lee instrucciones, las decodifica y genera señales para coordinar el resto del sistema.

ALU

Realiza operaciones aritméticas y lógicas: sumar, comparar, desplazar o evaluar condiciones.

Registros

Memorias internas muy rápidas que guardan datos de uso inmediato.

CPU · Unidad de control · ALU · Registros
Conecta esta diapositiva con el ciclo de instrucción: buscar instrucción, decodificar, ejecutar y guardar resultado. No hace falta entrar aún en microarquitectura, solo fijar el mapa mental.

Comunicación interna

Los buses son las carreteras del sistema.

Bus de datos

Transporta la información que se lee o escribe.

Bus de direcciones

Indica dónde está la memoria o dispositivo que se quiere usar.

Bus de control

Coordina señales como lectura, escritura, reloj e interrupciones.

3

Una operación, tres tipos de señales

Para leer un dato, la CPU necesita indicar una dirección, activar una señal de lectura y recibir los datos por el canal correspondiente.

Buses del PC
Cuenta un ejemplo: la CPU quiere leer una celda de memoria. Primero pone la dirección, luego envía la señal de lectura y finalmente recibe el dato. Así se entiende por qué los buses no son “un cable” sino un conjunto de líneas con funciones diferentes.

Resumen final

Cinco ideas para llevarse.

1

Hardware y software trabajan juntos.

2

El PC transforma datos en información útil.

3

La CPU coordina instrucciones y operaciones.

4

La memoria sostiene lo que está en uso.

5

Los buses permiten que todo se comunique.
