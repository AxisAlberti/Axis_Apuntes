# Unidad 11 - Utilidades para el mantenimiento

## Resumen de la unidad

Esta unidad presenta las utilidades mas usadas en un taller para diagnosticar, mantener, reparar y documentar equipos. Incluye software libre y propietario, asi como criterios para elegir herramientas segun el caso.

## Que aprenderas

- Clasificar herramientas por uso (diagnostico, almacenamiento, seguridad, redes, productividad).
- Seleccionar software segun licencia, soporte y requisitos del cliente.
- Aplicar instrucciones basicas de uso y buenas practicas en taller.
- Identificar fuentes oficiales de descarga y verificacion.
