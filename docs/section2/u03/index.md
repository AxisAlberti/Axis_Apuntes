# Unidad 03 - Docker

## Resumen de la unidad

Esta unidad introduce Docker como tecnologia de contenedores. El objetivo principal es comprender con claridad que es Docker, que es una imagen, que es un contenedor y por que esta herramienta se usa tanto en desarrollo, pruebas y despliegue, teniendo en cuenta tanto Linux como Windows.

## Que aprenderas

- Explicar con tus palabras que es Docker.
- Diferenciar imagen, contenedor y registro.
- Comparar un contenedor con una maquina virtual.
- Entender el flujo basico de trabajo con Docker.
- Reconocer diferencias practicas entre Linux y Windows al usar Docker.
- Entender para que sirve Docker Compose y como se estructura un fichero `compose.yaml`.
